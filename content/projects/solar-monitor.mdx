A solar-powered LED lighting system that measures itself. An INA219
current/voltage sensor and an LDR track panel output under changing light,
while an Arduino crunches the numbers and reports live efficiency on a
0.96" OLED.

Built as the final project for Embedded Systems — photovoltaic panel,
microcontroller, and sensor array integrated into one self-reporting unit.

## Specifics

- INA219 current/voltage sensing with an LDR light reference
- Arduino firmware computing live efficiency under changing light
- Photovoltaic panel, LED load, and sensor array integrated into one unit
- Live metrics on a 0.96″ I2C OLED readout
