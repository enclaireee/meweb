The full-stack platform for KOMAT UNPAR, a national mathematics competition
hosted by Universitas Katolik Parahyangan. Built end-to-end: an animated,
fully responsive participant-facing site, plus an admin dashboard handling
registration and payments for participants across the country.

Shipped on Next.js 15 with Tailwind v4 and Framer Motion, deployed to Vercel
with continuous delivery — maintained in production through the full
competition cycle.

## Specifics

- Participant-facing frontend with interactive animation, fully responsive
- Admin dashboard with integrated registration and payment flows
- Continuous delivery to Vercel via GitHub through the live competition cycle
